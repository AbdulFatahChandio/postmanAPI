# Post API Testing

This repository contains automated tests for validating the functionality of a RESTful **Post API**. It is designed to ensure that the API performs as expected for various CRUD operations (Create, Read, Update, Delete).

## 🚀 Features

- Test POST, GET, PUT, DELETE endpoints
- Validate HTTP response codes and structures
- Check edge cases and error handling
- Easy configuration and environment setup

## 📦 Tech Stack

- Node.js
- Express (if mocking the server)
- dotenv for environment configuration
- Postman (optional - for manual testing)
